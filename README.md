# מילה אחרי מילה: APK

משחק תרגול שליפת מילים לילדים, עטוף כאפליקציית אנדרואיד (Capacitor) ונבנה אוטומטית ב-GitHub Actions.

## מבנה
- `src/index.html` – קוד המשחק (כאן עורכים מילים ועיצוב)
- `recordings/` – הקלטות אישיות, קובץ לכל מילה (`כלב.m4a`, `לרוץ.mp3`)
- `scripts/build_audio.py` + `scripts/pronunciations.json` – הפקת אודיו והטמעתו במשחק
- `.github/workflows/android.yml` – הבנייה

## בנייה
1. דוחפים ל-GitHub (ענף `main`). הבנייה מתחילה לבד.
2. ב-Actions נכנסים להרצה האחרונה ומורידים את `word-by-word-apk`. בפנים `app-debug.apk`.
3. מעבירים לטלפון ומתקינים (נדרש לאשר "התקנה ממקורות לא ידועים").

## קול
- הקלטות בתיקייה `recordings/` מוטמעות אוטומטית בכל בנייה.
- הרצה ידנית (Actions ← Run workflow) מאפשרת לבחור מנוע: `edge` (חינמי, לא רשמי) או `azure`.
  עבור azure מוסיפים ב-Settings ← Secrets: `AZURE_SPEECH_KEY` ו-`AZURE_SPEECH_REGION`.
- מילה בלי אודיו מוקראת בקול של המכשיר, אם קיים.

## APK חתום להפצה (לא חובה)
מוסיפים Secrets: `KEYSTORE_BASE64` (תוצאת `base64 -w0 release.keystore`), `KEYSTORE_PASSWORD`, `KEY_ALIAS`.
ליצירת מפתח: `keytool -genkeypair -v -keystore release.keystore -alias wbw -keyalg RSA -keysize 2048 -validity 10000`
**שומרים את המפתח והסיסמה במקום בטוח.** בלעדיהם אי אפשר לעדכן את האפליקציה.

## בנייה מקומית
`npm install && npm run audio && npx cap add android && npx cap sync android` ואז פתיחה ב-Android Studio.

## שיתוף סיכום תרגול
בבקרת מלווים (לחיצה ארוכה על ⚙️) יש קטע "שיתוף סיכום עם גורם מקצועי". מזינים אימייל וטלפון, בוחרים תקופה, רואים ועורכים את הסיכום, ושולחים בלחיצה לוואטסאפ, לטלגרם, לאימייל או לתפריט השיתוף של המכשיר.
השליחה תמיד ידנית: האפליקציה לא שומרת שרת ולא שולחת דבר לבד. הסיכום אנונימי אלא אם מסמנים לכלול שם.

## רמות
יש עשר רמות לפי מורכבות המילה (הברות, אורך, צירופי עיצורים, רבים, פועל ושכיחות). במצב אוטומטי הילדה מתחילה ברמה 1 ועולה אחרי סבב שבו לפחות 75% מהמילים נשלפו בלי שלושת הרמזים. הרמה לא יורדת מעצמה. אפשר גם לבחור רמות ידנית בבקרת מלווים.

## התאמות לפי מחקר
- רמזים בשני סוגים: משמעות ומקום, וצליל (צליל ראשון ואז הברה ראשונה). אפשר לשנות את הסדר ולבחור אילו רמזים זמינים.
- שליפה חוזרת במרווחים: מילה קשה חוזרת באותו סבב אחרי כמה מילים, ובימים הבאים לפי לוח זמנים (0, 1, 3, 7, 14, 30 ימים).
- אחרי חשיפת המילה מזמינים את הילדה להגיד אותה בקול.
- מילים אישיות שמוסיפים בבקרת מלווים, כי השיפור במחקרים היה בעיקר במילים שתורגלו.
- משימה קטנה לבית בסוף סבב, לחיבור לשימוש יומיומי.
- הסיכום לשיתוף כולל אחרי איזה סוג רמז נשלפו המילים, ומגמה בשיעור המילים שנשלפו בלי רמז.
האפליקציה לא נבדקה בניסוי, והיא תרגול תומך ולא תחליף לקלינאית תקשורת.

## משחק משפטים
לכל מילה יש משפט עם מקום ריק. המשפט הוא רמז הקשרי, ואפשר לבקש את אותם רמזים. אחרי חשיפת המילה מראים את המשפט המלא, מזמינים להגיד אותו בקול, ואפשר לחשוב על משפט משלי עם התחלות מוכנות. ברמות 8 עד 10 התמונה מוסתרת ונחשפת כרמז (אפשר להסתיר אותה בכל הרמות בבקרת מלווים).
הסקריפט `scripts/build_audio.py` מפיק אודיו גם למשפטים (`--no-sentences` מכבה). הקלטה אישית של משפט: `recordings/משפט_כלב.m4a`.
המשפטים מוצגים בלי ניקוד, והמילה החסרה מופיעה מנוקדת רק אחרי החשיפה.
